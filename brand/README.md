# Identité LazySyndic

Le symbole est une **façade bruxelloise à pignon à gradins** : un immeuble, plusieurs lots,
la fenêtre argile pour « votre » lot. Le nom est composé en Hanken Grotesk droit
(« Lazy » gras, « Syndic » demi-gras), vectorisé : les fichiers ne dépendent d'aucune police.

| Fichier | Usage |
|---|---|
| `logo.svg` | logo horizontal, fonds clairs (site, rapports, documents) |
| `logo-white.svg` | logo horizontal, fonds verts ou sombres (barre latérale, pied de page) |
| `logo-ink.svg` | une seule encre (impression noir et blanc, tampons) |
| `mark.svg` / `mark-white.svg` | symbole seul, carré à coins arrondis |
| `wordmark.svg` | nom seul |
| `favicon.svg` | onglet du navigateur |
| `icon-180.png` | icône d'écran d'accueil iPhone (plein cadre, iOS arrondit lui-même) |
| `og.png` | aperçu 1200 × 630 quand le lien est partagé (WhatsApp, LinkedIn, e-mail) |

## Couleurs

| Nom | Valeur | Rôle |
|---|---|---|
| Vert profond | `#21503D` | couleur de marque, fond du symbole |
| Vert | `#2F6B53` | « Syndic », accents, boutons |
| Argile | `#C9854A` | la fenêtre du symbole, accents rares |
| Papier | `#F4F0E6` | fond, façade du symbole |
| Encre | `#20251F` | texte |

## Règles

- Pas d'italique dans le logo, pas de déformation, pas d'ombre.
- Laisser autour du logo une marge au moins égale à la moitié de la hauteur du symbole.
- Taille minimale : symbole 16 px, logo horizontal 24 px de haut.
- Une seule famille partout : Hanken Grotesk (titres en 700, texte en 400–500).
